# Nik. — Personal Developer Portfolio

A modern, responsive developer portfolio built with **React, Vite, and CSS3** to showcase my projects, technical skills, education, and journey as a software developer.

Designed with a minimal dark-purple aesthetic, smooth interactions, and a focus on usability across devices.

### 🌐 Live Website

**[View My Portfolio](https://nik-portfolio.onrender.com)**

---

## ✨ Features

- **Responsive Design** — Optimized layouts for desktop, tablet, and mobile devices.
- **Interactive Hero Section** — Personal introduction, animated developer roles, and project navigation.
- **Project Showcase** — Featured project display with a horizontally scrollable carousel for additional projects.
- **Technology Stack** — Categorized skills with interactive tabs and technology icons.
- **About Me** — Personal background, interests, and social profile links.
- **Education & Achievements** — Academic information, competition achievements, and certificate access.
- **Functional Contact Form** — EmailJS integration for sending messages directly from the website.
- **Resume Access** — Dedicated navigation button for accessing my resume.
- **Modern UI** — Custom CSS styling, subtle hover effects, and a consistent dark-purple theme.

## 🚀 Getting Started

To run this project locally:

**1. Clone the repository**

```bash
git clone https://github.com/nikhilikdevx/Nik.git
cd Nik
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

Create a `.env` file in the project root:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

These values are required for the contact form to send messages.

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal.

**5. Create a production build**

```bash
npm run build
```
